# Task Workflow - Package Summary

High-level overview of the task workflow skill system.

## Purpose

Provides unified task workspace management for development projects with:
- Standardized workspace structure
- Git worktree integration
- Tmux session management
- GitHub issue tracking
- Progress documentation

## Components

- **SKILL.md**: Core invocation logic
- **references/**: Detailed documentation modules
- **scripts/**: Shell utilities for workspace operations
- **templates/**: File generation templates

## Usage

Invoked by slash commands or automatically by Claude based on context.
