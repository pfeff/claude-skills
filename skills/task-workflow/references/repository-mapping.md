# Repository Mapping Reference

Path resolution and repository location logic.

## Repository Locations

- `~/src/github/<user|org>/<repo>` - GitHub repositories
- `~/src/sourceforge/<project>/<repo>` - Sourceforge repositories

## Worktree Path Convention

`~/src/work/<project-slug>/<issue-slug>/<repo-name>/`
